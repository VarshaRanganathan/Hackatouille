Please build the complete, polished mobile web application for ResilientBank in `src/App.jsx` using React and Tailwind CSS. The interface must use simple, everyday language that gig workers and freelancers can easily understand—avoiding complex banking jargon.

Use a modern Indian fintech visual design: deep emerald green (`#0F4135`) for brand buttons/accents, soft off-white background (`#F8F9FA`), clean rounded white cards, dark charcoal text, green for safe/positive numbers, and amber for bill alerts. Use Indian Rupees (₹) everywhere.

Build these core sections and make them accessible through the persistent 5-tab bottom bar [Home] [Resilience] [Save] [Credit] [Guidance]:

1. Top Bar & Simple Profile Switcher:
   - ResilientBank logo (Shield + Leaf) and a user picker button showing the current name ("Ravi • Delivery Worker").
   - Clicking the name opens a simple sheet modal to pick between all 30 mock users (`GET /api/users`).
   - Include quick header buttons for Data Control (lock icon) and Notifications (bell icon).

2. Home Tab:
   - "How much do I have?": Big clear text showing Available Balance (₹6,850) and Safe-to-Spend (₹2,300).

   - "What should I do today?": Daily recommendation card ("Your earnings were higher this week. You can safely save ₹300 today.") with 3 buttons: [ Save ₹300 ], [ Adjust ], and [ Skip ]. Include a "Why ₹300?" button that opens an easy-to-read mathematical explanation modal.

3. Resilience Tab:
   - Resilience Score gauge (68/100) and Buffer Days indicator ("12 days covered").
   - 30-day balance forecast chart highlighting any low-income periods.
   - Factor breakdown list (Income steadiness, Savings balance, Cash ups and downs) with an "Explain my score" button that opens a plain-English explanation drawer.

4. Save Tab:
   - Emergency Goal progress bar (₹3,400 / ₹5,000 target).
   - Safe-to-Save Calculator: Input boxes for Daily Income and Expenses to calculate safe daily savings (`Income - Expenses - Safety Buffer`).
   - Choice of saving styles: Round-up spare change, % of Income, or Smart Save.

   - Purpose selector (Vehicle repair, Medical, Bridge to next income) and an input box for Requested Amount.

7. Drawers & Extras:
   - Data Control Drawer: List of connected accounts with one-tap "Stop Sharing" and "Delete My Data" buttons.
   - Smart Notifications Drawer: Categorized into Urgent (Bills due, low cash) and Good to know (Surplus earnings, score updates) with a frequency setting (Quiet, Balanced, Helpful).
   - System Loop Footer: A subtle visual bar depicting background safety checks (Income received -> Cash flow calculated -> Safety check -> App updated).

Ensure all data updates dynamically using the Express API endpoints (`GET /api/dashboard/:userId`, `POST /api/savings/calculate`). Keep all notification toasts anchored safely at the top of the screen (`z-50`) so they never block buttons.
