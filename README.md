# ResilientBank 🏦

Financial resilience for individuals with irregular and gig-based incomes.

## Overview
ResilientBank turns income volatility into financial stability using dynamic cash-flow forecasting, automated micro-savings, and responsible credit guardrails.

## Core Features
- **Savings Engine**: Calculates daily safe-to-save amounts based on income and upcoming expenses.
- **Resilience Score & Buffer Days**: Tracks financial stability and provides a 14-day cash-flow forecast.
- **Responsible Credit**: Grants loans based on cash-flow patterns with strict affordability circuit breakers.
- **Smart Notifications**: Context-aware alerts that dynamically throttle based on user activity.
- **What-If Simulator**: Predicts how financial behaviors impact Buffer Days without moving actual funds.

## Tech Stack
- **Frontend/Backend**: Node.js / React / Express
- **Database & Auth**: Supabase (PostgreSQL)
- **Deployment**: Replit
